# U.S. Airline Routes & Fares — Exploratory Data Analysis

## Project Overview
This project conducts exploratory data analysis (EDA) on U.S. airline routes and fares from 1993–2024 to identify patterns in airfare, passenger volume, route distance, carrier market share, and pricing behavior.

## Objectives
- Perform univariate, bivariate, and multivariate analysis
- Conduct correlation analysis
- Detect airfare trends over time
- Explore important features
- Present and interpret key insights

## Tools Used
Python, Pandas, NumPy, Matplotlib, Seaborn, Statsmodels, and Jupyter Notebook.

## Key Findings
- Route distance has a moderate positive correlation with airfare (r = 0.50).
- Passenger volume has a weak negative correlation with airfare (r = -0.17).
- Carrier fares are strongly associated with overall market airfare.
- The regression model explains approximately 32% of airfare variation.
- Airfare is associated with route characteristics, passenger demand, carrier pricing, market structure, and time.
