# Dataset

This project uses the U.S. Airline Flight Routes and Fares dataset (1993–2024).

## Download

Download the dataset from the original project source:

https://drive.google.com/file/d/1MW9rbiXF-1CYc9NXpY0NM8TbKVe3nqd6/view?usp=sharing

After downloading, save the CSV file in this folder as:

`US_Airline_Fares.csv`

The raw CSV file is excluded from this GitHub repository using `.gitignore`.
